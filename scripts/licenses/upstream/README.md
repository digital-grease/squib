# Licence texts from upstream repositories

Some published crates ship without their licence file. For those, the text here was
copied from the crate's own source repository, so the About screen can show the
copyright notice the licence requires. `scripts/third_party_notices.py` uses a file
here only when the published crate has no licence file of its own.

| File | Crate | Source |
|---|---|---|
| `cookie-factory.txt` | cookie-factory 0.3.3 (MIT), used by age | https://github.com/rust-bakery/cookie-factory/blob/master/LICENSES/MIT.txt |
